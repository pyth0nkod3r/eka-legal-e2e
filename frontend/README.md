# Eka Legal
 
Eka Legal Consultancy - Trusted Legal Solutions.
 
## Project Info
 
This project is a web application for Eka Legal Consultancy, built to provide legal services and information to clients.
 
## Technologies
 
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
 
## Getting Started
 
1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Run development server: `npm run dev`
