# Eka Legal API

FastAPI backend for Eka Legal Consultancy practice management system.

## Development

```bash
# Sync dependencies
uv sync

# Run the server
uv run uvicorn app.main:app --reload

# Run tests
uv run pytest
```

## API Documentation

Once running, visit:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
